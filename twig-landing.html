How to Use Twig

Automatic error detection and resolution

Twig detects errors in production, understands their impact through PostHog data, and generates fixes automatically. It sees the stack trace, correlates it with user sessions, and ships a PR with the fix.

TypeError: Cannot read property 'user' of undefined at CheckoutPage.tsx:47
→ Twig detected this error affecting 234 users
→ Generated fix: added null check
→ PR #1424 opened, tests passing
Capabilities What Twig does for your codebase
01

PostHog Integration

Connects directly to your PostHog instance. Sees what your users see—session replays, error events, rage clicks—all feed the agent context.

02

Multi-Agent Orchestration

Run up to 32 concurrent agents. Planners, executors, verifiers—each with specific roles. Parallel execution across your codebase.

03

Autonomous PR Creation

Detects issues, reasons about fixes, writes code, runs tests, opens PRs. Full pipeline from error to deployed fix.

04

Fine-Grained Control

Set throttles, autonomy levels, approval gates. Pause agents, kill tasks, adjust priorities. You decide how much control to give.

05

Model Agnostic

Works with GPT-4, Claude, Llama, or your own fine-tuned models. Swap providers without changing workflows.

06

Real-Time Monitoring

Watch agents think. See token usage, task progress, decision trees. Full visibility into what's running and why.

The future of software development is agentic.

Twig connects to your PostHog instance and understands how real users interact with your product. When errors happen, when users rage-click, when flows confuse—Twig sees it, reasons about it, and ships the fix.
